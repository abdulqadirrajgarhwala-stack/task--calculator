# CODSOFT Task 2 - Simple Calculator

## 📌 Project Overview

This project is a **Simple Calculator** developed using Python as part of the **CODSOFT Python Programming Internship**.

The application allows users to enter two numbers, select an arithmetic operation, and display the calculated result.

The calculator performs the four basic arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

---

## 🎯 Objective

The objective of this project is to design a simple calculator application that:

- Prompts the user to enter two numbers
- Allows the user to select an arithmetic operation
- Performs the selected calculation
- Displays the result clearly
- Handles invalid input
- Prevents division by zero

---

## ✨ Features

### ➕ Addition
Adds the first number to the second number.

### ➖ Subtraction
Subtracts the second number from the first number.

### ✖️ Multiplication
Multiplies the two numbers.

### ➗ Division
Divides the first number by the second number.

### ⚠️ Error Handling
The application handles:

- Invalid number input
- Invalid operation choices
- Division by zero

---

## 🛠️ Technologies Used

- **Python 3**
- Python built-in functions
- Conditional statements
- Exception handling
- Arithmetic operators

No external libraries are required.
